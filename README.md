# babrs/games

Игровая платформа экосистемы Babrs: статический SvelteKit (`@sveltejs/adapter-static`), стили и компоненты из `babrs-ui`.

- Зависимость: `"babrs-ui": "github:Babrs/ui"`.
- Сборка: `npm run build` (результат в `build/`, база `/games`).
- Публикация: GitHub Pages `https://babrs.github.io/games/` через `.github/workflows/deploy.yml`.
